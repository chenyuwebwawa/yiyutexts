# 译语输入法 YuyinIme

> 打字即记单词 —— 打拼音，上屏外语词。

**中文** | [English](README_EN.md)

一个轻量的系统级输入法：**它首先是一个能打中文的输入法** —— 打拼音出中文候选，空格上屏中文；每条候选右侧附带外语释义，按数字键上屏外语词。每天打字的同时，自然积累外语词汇。

Windows 本体是 **260KB 单文件**，无需注册、无需管理员权限、无任何依赖，双击即用。

## ✨ 特性

- **系统级**：全局键盘输入，浏览器、微信、记事本、Office 全部可用
- **打字即背词**：`nihao` → `hello`、`weiji` → `crisis`，上屏即所学
- **全量词典**：英语 10.4 万条（CC-CEDICT），完全离线
- **智能联想**：上屏一个词后自动预测下一个词（本地二元模型）
- **词频学习**：你上屏过的词自动置顶，越用越顺手（数据纯本地）
- **候选窗跟随光标**：定位在文本光标正下方，自动避让屏幕边缘，深浅色自适应
- **中英混输**：拼不出词时回车原样上屏，中英文无需切换
- **29 种语言**：英语内置全量，其余语言通过词汇包扩展（泰语、匈牙利语、土耳其语、斯瓦希里语……）

## ⌨️ 按键

| 按键 | 功能 |
| --- | --- |
| 字母键 | 组拼音，中文候选 + 外语释义并列显示 |
| `空格` / `回车` | **上屏中文**（像正常输入法），并联想下一个词 |
| `1`–`8` | **上屏外语词**（学习动作） |
| `<` `>` / `↑` `↓` | 翻页 / 移动高亮 |
| `Esc` | 取消组字 |
| `退格` | 删除字母（删空后自动交还系统） |
| 字母键 | 外语模式中组拼音，候选窗跟随文本光标 |
| `1`–`8` | 选词（外语词上屏），上屏后自动联想下一个词 |
| `空格` / `回车` | 上屏首选；无候选时原文直通并退出外语模式 |
| `<` `>` / `↑` `↓` | 翻页 / 移动高亮 |
| `Esc` / `退格` | 退出外语模式 / 删除字母 |
| `Ctrl+Space` | 总开关（暂停 / 恢复整个输入法） |
| `Ctrl+Alt+Q` | 退出程序 |

典型流程：打 `nihao` → 候选显示 `你好 hello` → 空格上屏「你好」（正常打字）→ 想学外语时按 `1` 上屏 `hello`。联想面板继续预测下一个词。

## 📦 安装

### Windows（一键安装包）

1. 下载 `YuyinIme-Setup.exe`（[Releases](../../releases)）
2. 双击 → 下一步 → 完成（自动启动 + 开机自启 + 桌面快捷方式）
3. 任意输入框：打 `nihao` → 空格上屏「你好」，按 `1` 上屏 `hello` —— 中文和外语都在你自己手里

**升级**：直接双击新版 `YuyinIme-Setup.exe` —— 安装器自动结束旧进程、覆盖程序、**保留你的学习数据**（词频与联想记忆跨版本延续）并重启输入法，无需先卸载。

**卸载**（三种方式任选，自动清理全部文件）：
- 开始菜单 → 译语输入法 → 卸载译语输入法
- Windows 设置 → 应用 → 已安装的应用 → YuyinIme
- 直接运行 `%LOCALAPPDATA%\YuyinIme\Uninstall.exe`

### macOS

1. 下载 `YuyinIme-macOS.dmg`，把 YuyinIme.app 拖入 Applications
2. 首次使用：在「系统设置 → 隐私与安全性 → 输入监控」中勾选 YuyinIme（安装器会自动打开该页面引导）
3. 菜单栏出现「译」图标即运行中

**卸载**：
```bash
./mac-setup.sh uninstall
```

### 从源码构建

```bash
git clone https://github.com/chenyuwebwawa/yiyutexts.git
cd yiyutexts

# Windows（需要 VS2022 Build Tools C++ 工作负载）
python tools/compile.py

# macOS（需要 Xcode Command Line Tools）
./mac-setup.sh
```

安装包（Windows NSIS / macOS dmg）通过 GitHub Actions 云端构建：推送 `v*` 标签自动出包。

## 🌍 语言扩展

```bash
python tools/build_dict.py en      # 英语全量（默认，104,834 条）
python tools/build_pack.py all     # 生成全部 29 种语言词汇包（断点续跑）
python tools/build_dict.py th      # 用泰语包生成 dict.tsv
```

**图形化切换（推荐）**：托盘右键 →「切换语言...」，列表中双击即切、即时生效。安装包已自带语言包（`packs/` 目录），离线可用。

命令行方式（生成自定义词库时用）：把生成的 `dict.tsv` 放到输入法同目录重启即可。词汇包使用 MyMemory 在线翻译生成，缓存于 `packs/_cache/`（每日限额用完后次日重跑自动续传）。

支持的语言：泰语、越南语、缅甸语、老挝语、柬埔寨语、马来语、印尼语、印地语、乌尔都语、孟加拉语、尼泊尔语、僧伽罗语、匈牙利语、芬兰语、土耳其语、希腊语、波兰语、捷克语、罗马尼亚语、塞尔维亚语、保加利亚语、乌克兰语、阿尔巴尼亚语、波斯语、希伯来语、斯瓦希里语、豪萨语、蒙古语、菲律宾语。

词典格式（Tab 分隔）：`拼音键 \t 外语词 \t 中文`

## 🏗️ 架构

```
按键 → 全局键盘拦截(WH_KEYBOARD_LL / CGEventTap) → 拼音缓冲
     → 词典查询(内存 hash，词频加权排序) → 上屏后二元联想预测下一词
     → 候选窗(光标定位，分层悬浮窗，深浅自适应) → 数字键 → 模拟键入上屏
```

- 单进程、无服务、无注册表（除一个可选的开机自启项）
- 学习数据（`freq.tsv` / `bigram.tsv`）100% 存本地，不上传任何内容
- Windows 与 macOS 共用同一份词典文件与交互逻辑
