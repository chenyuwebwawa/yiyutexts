下载与安装

全部免费开源（MIT）

🪟 Windows

  1. 下载 YuyinIme-Setup.exe（1.7MB）
  2. 双击 → 下一步 → 完成（自动启动 + 开机自启）
  3. 任意输入框打 nihao，空格上屏「你好」，按 1 上屏 hello
升级：直接运行新版 Setup，学习数据自动保留
卸载：开始菜单 / 系统设置 → 应用 / Uninstall.exe
便携版：zip 解压即用
获取 Windows 版

🍎 macOS

  1. 下载 YuyinIme-macOS.dmg，拖入 Applications
  2. 首次使用：系统设置 → 隐私与安全性 → 输入监控 中勾选 YuyinIme
  3. 菜单栏出现「译」即运行中
卸载：./mac-setup.sh uninstall
开机自启：安装时自动配置 LaunchAgent
获取 macOS 版
