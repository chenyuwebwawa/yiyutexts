打字，就是背单词

我做了个「译语输入法」：打拼音，上屏外语词

你有没有过这种体验——

单词书永远停在 abandon；背了三年的 persistent，写的时候还是想不起来；收藏了一堆「一个月记住 5000 词」的方法，最后都变成了收藏夹里的灰。

因为背单词违背了人的天性，而用单词不会。

所以我干脆做了一个输入法：译语输入法（YuyinIme）。你在任何地方打拼音，它给你外语候选——

↑ 打 nihao，上屏的是 hello（真实截图）

打个招呼，顺手就说了句匈牙利语的 Szia；想写"谢谢"，候选窗里躺着泰语的 ขอบคุณ 和斯瓦希里语的 Asante。一天打几百次"你好"，一个月就是几百次 hello / Merhaba / Jambo。

◆ ◆ ◆

它不耽误你打中文

这是设计的第一原则。平时打字，它一个键都不碰，微软拼音、搜狗该怎么用还怎么用。

想冒个外语词的时候：

① 按 `（Tab 上方那个键）
② 打拼音 nihao，候选窗出现
③ 按空格 —— hello 上屏，回到中文，全程 3 秒

越用越「懂你」

它带一点本地学习能力：

📩 你上屏过的词，下次自动排到候选最前面；
🧠 上屏 hello 之后，它会猜你的下一个词；
🔒 这些习惯全部存在你自己的电脑里，不联网、不上传。

小到不像个软件

Windows 版是一个 260KB 的单文件——还没有一张表情包大。没有弹窗、没有广告、没有会员，内存占用约 30MB。

词典是全量的：10.4 万条英文释义离线可查，连"鼹""邃"这种生僻字都有对应翻译。另外还准备了29 种语言的词汇包——泰语、匈牙利语、土耳其语、斯瓦希里语这些"一带一路"语言，一键切换。

⌨️ 按键速查

` 进入/退出外语模式　 1-8 选词　 空格 上屏首选
< > 翻页　 Esc 回到中文　 Ctrl+Space 总开关

怎么获取

Windows / macOS 都有安装包，完全免费开源（MIT 协议）：

📦 Windows：YuyinIme-Setup.exe（1.7MB，双击装完即用）
🍎 macOS：YuyinIme-macOS.dmg（拖入 Applications）
🔗 下载地址：github.com/chenyuwebwawa/yiyutexts/releases

不方便访问 GitHub 的朋友，可以在后台回复「输入法」获取网盘链接。

语言学习没有捷径，但可以有顺路的车。愿你敲下的每一个字，都顺便记住一个单词。

觉得有用的话，点赞、在看、转发 给那个总说"单词背不下来"的朋友吧。
