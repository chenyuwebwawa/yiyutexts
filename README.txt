译语输入法 YuyinIme
==================

打字即记单词的系统级输入法 —— 打拼音，上屏外语词。

【使用】
1. 双击"译语输入法"启动（托盘有图标，已设开机自启）
2. 在任何应用的输入框中直接打拼音，如 nihao、shijie、weiji
3. 候选窗出现后按数字键 1-8 选词，外语词直接上屏
4. < > 翻页，↑ ↓ 移动，回车=原样上屏（中英混输），Esc=取消

【开关】
Ctrl+Space  开/关输入
Ctrl+Alt+Q  退出程序

【换语言】
把对应语言的 dict.tsv 覆盖到本目录后重启程序。
词典生成器与源码见项目仓库。

【卸载】
开始菜单 → 译语输入法 → 卸载译语输入法
